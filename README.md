Be Careful is a progression and difficulty overhaul that aims to change the way players interact with the world around them. 

Certain dimensions or biomes, such as the Nether or the Deep Dark, require more preparation or specific buffs or items to be able to progress through safely.

Global difficulty has been inverted per chunk, such that every chunk starts in the hardest difficulty state and is "tamed" with the more time spent in them.

These are some of the many additions and changes made in this mod, almost all of which are configurable so you may pick and choose what you would like to keep.

## Dependencies

- **[Fabric API](https://modrinth.com/mod/fabric-api)** - For Fabric versions
- **[NeoForge](https://neoforged.net/)** - For NeoForge version
- **[MidnightLib](https://modrinth.com/mod/midnightlib)** - Provides config
